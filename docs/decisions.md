# 決定ログ（おはぎのおさんぽ帳）

## 2026-11-16 企画（ユーザー決定）

- **位置づけ**：おはぎきなこ工房の公式アプリ。売上よりブランドとファンづくり（チワちくシリーズの「付録」）。おはぎ・しらたま・きなこ・ようかん・どらやきがアイコンや画面に出る、やさしい雰囲気。
- **競合調査**（2026-11-16、22本・レビュー約900件）：候補の機能（Watch ワンタップ、iCloud でアカウントなし共有、日本語、前回からの経過時間、病院向け一覧）はどれも既にどこかにある。いちばん近いのは「肉球ログ」（2026-10 公開、日本語・Watch・iCloud 家族共有無料、¥200/月・¥3,000 買い切り）。低評価の不満の上位は、記録の失敗・ログイン・更新で使いにくくなった・課金・データ消失・家族共有の同期。詳しくはセッションの共有メモ `chiwa-walk-chosa.md`（リポジトリ外）。
- **差をつける柱（3つ）**：
  1. **Watch だけで完結**：腕で1回押す → 振動で確認、すぐ取り消せる、文字盤に「前回のうんちから◯時間」。iPhone を持たなくても記録できる。
  2. **消えない・ログインなし**：端末に先に保存し、自分の iCloud で同期。家族共有は iCloud の共有で招待（サーバーを持たない）。
  3. **複数の犬をまとめて記録**：一緒に散歩している犬を選んで一度に記録。
- **アプリ名**：App Store の名前「**おはぎのおさんぽ帳 - 犬のトイレ記録**」、ホーム画面の短い名前「**おさんぽ帳**」。App Store 検索（2026-11-16）で同名なし。
- **お金**：**機能はすべて無料**・**広告なし**。任意の「応援」買い切り **100円**（ユーザー決定）。お礼は着せ替え（おはぎ以外の4匹）だけ。家族共有・犬の数・病院向け一覧は無料。
  - 当初は「100円で家族共有・3匹以上・一覧・着せ替えを解放」の案だったが、無料で機能の多い競合（TailRoute・onedog など）があるため、機能を閉じない形に変えた（ユーザー決定、同日）。
  - 広告をやめた理由：Watch には広告を出せない、広告の仕組みは利用情報を外部に送るため「記録を外に送らない」約束と合わない、広告への不満レビューもある。
- **リポジトリは公開**（クラウドの Mac が無料）。公開してよい素材だけ入れる。秘密の値は GitHub の Secrets に置く。
- **バンドル ID**：`com.ohagikinakokobo.osanpo`（iPhone）・`com.ohagikinakokobo.osanpo.watchkitapp`（Watch）。版は 1.0.0 から。
- **作り方**：pickle-score と同じく Mac なし（XcodeGen ＋ GitHub Actions のクラウドの Mac → TestFlight）。iOS 17／watchOS 10 以上。
- **守ること**：健康について医療的な判断や助言はしない（気になるときは動物病院へ）。位置情報は使わない。記録は端末とユーザー自身の iCloud の中だけ。

## 2026-11-16（2回目）仕様書承認・試作1

- **仕様書 v0.2 を承認**（ユーザー）。**地図（道すじの記録）とアルバムは最初の版に入れない**（競合の不満の最多が道すじ記録の失敗、Watch での位置取得にワークアウトとヘルスケアの許可が要る、電池、自宅の場所、写真の容量と同期）。あとで足す候補：オンオフできる地図、「その日の1枚」の写真。
- **アイコンは Gemini で描く**（ユーザー）。指示文は `docs/art/icon.md`。決まるまでは仮のアイコン（`tools/make_placeholder_icon.py`）。
- **記録の種類** [仮]：おしっこ・うんち・おみず・ごはん（2×2 の大きなボタン）＋おさんぽ スタート／おわり。散歩は時刻だけで、4時間たっても「おわり」がなければ散歩中とみなさない。
- **iPhone の保存**：Core Data（モデルはコードで定義）。家族共有に備えて「家（Household）→犬→記録」のつながりにした。iCloud は試作2でオンにする（今は端末の中だけ）。
- **Watch ↔ iPhone**：Watch は自分の中に先に保存し、iPhone へは順番待ちの送信（transferUserInfo）で送る（iPhone が家にあっても後で届く）。iPhone からは犬と最近2日分＋種類ごとの最新の記録を送る（applicationContext）。取り消しは「この記録を消す」を送る。同じ記録が二重に入らないよう、記録ごとの番号（UUID）で見分ける。
- **フォント**：犬の名前にどんな漢字でも使えるよう、M PLUS Rounded 1c Bold を文字を減らさず全部入れた（約 3.5MB）。
- **公開リポジトリ** https://github.com/shinichi-sunayama/chiwa-walk を作成。Linux のテスト（WalkCore 13件）と、クラウドの Mac での署名なしの組み立てが成功（2026-11-16、run 43777013808／43777013807）。

## 2026-11-16（3回目）写真・ボタン（ユーザー決定）

- **犬のアイコンに自分の犬の写真**を使える。iPhone 標準の写真選択（許可の確認なし）で選び、まんなかを正方形に切り抜いて 320px の JPEG（約20KB）で Core Data に保存（大きい値はファイルに逃がす設定。iCloud では添付ファイルとして同期される予定）。Watch には 96px の小さな版を、いつもの送信（applicationContext）に入れて送る。おはぎたち5匹の絵と足あとも選べるまま。
- **ボタンは「おしっこ」「うんち」の2つが標準**（Watch では1段の特大ボタン）。「おみず」「ごはん」は せってい でオンにすると増え、Watch にも反映（2つずつの段に並べ、奇数なら最後は横いっぱい）。
- **言い方は「おしっこ・うんち」のまま**（競合もほぼ同じ。「排泄」1つにまとめると前回のうんちからの時間が出せない）。ストアの説明には「トイレ（排泄）記録」と書く。
- **ボタンの絵は工房のイラスト**（Gemini、`docs/art/buttons.md`）。`assets/kinds/<種類>.png` があればそれを、なければ絵文字を出す。うんちはソフトクリーム型のかわいい記号で顔なし、ごはんはドッグフードのお皿。

## 2026-11-17 アイコン決定（ユーザー選択）

- Gemini で描いた「赤いリードでおさんぽ中のおはぎ＋芝生の上の手帳＋足あと」（2000×2000）を採用。`docs/art/icon/app_icon_gemini.jpg`。小さく表示しても、Watch の丸い切り抜きでも犬の顔が残ることを確認。
- 1枚目が荒かった原因は見本の絵が 118×180 と小さかったこと。見本を 1024px の `reference_ohagi.png` に替え、線・手帳・足あと・ふちの指定を足して描き直した。
- **ボタンの絵（2026-11-17）**：おしっこ（しずく3つ、Gemini の SVG）とうんち（ソフトクリーム型・顔なし、Gemini）を採用。表現は絵文字と同じ程度の記号で、リアルさ・顔・食べ物に見える演出はなく問題なしと判断。ボタンの色と同じ黄色のしずくが見えなくなるため、絵は**白い丸の上に**のせる。SVG はベクターのままアセットに入れる。おみず（犬用の水入れ）・ごはん（ドッグフードのお皿）も同日に採用し、4つとも工房の絵になった（絵文字は絵がないときの予備）。

## 2026-11-17 登録待ちの間に進めたこと（ユーザー了承）

- **犬5匹の絵をくっきりした版に**：chiwa-photo の 3D モデル描き出し（約340px）から、丸いアイコン用に顔のまわりを切り出した 320px に差し替え（`tools/make_dog_faces.py`）。以前の 118×180 は iPhone でぼやけていた。
- **Watch の文字盤（コンプリケーション）**：WidgetKit の拡張を追加。丸・角・1行・長方形に対応。長方形は「いっしょの犬」最大3匹の「💩○時間 💦○分」、丸・角・1行はいちばん新しいうんちからの時間。Watch アプリが App Group（`group.com.ohagikinakokobo.osanpo`）に「最後の時刻」を書き、文字盤は10分ごとの表示を4時間分作って自分で進める。計算は WalkCore の `ComplicationData`（テストあり、計17件）。
- **App Group と iCloud の入れ物を今の登録で一緒に作ってもらう**：文字盤のために3つ目のバンドル ID（`…watchkitapp.widget`）と App Group が必要になったので、試作2で使う iCloud Container（`iCloud.com.ohagikinakokobo.osanpo`）も同じ手順に入れた（`docs/ios-testflight.md` の 2-0・2-1）。
- **プライバシーポリシーとサポートのページ**を `site/` に作り、GitHub Pages で公開：https://shinichi-sunayama.github.io/chiwa-walk/privacy.html ・ https://shinichi-sunayama.github.io/chiwa-walk/support.html 。連絡先は pickle-score と同じ工房のメール。iCloud・家族共有・応援の購入（1.0 で入る予定のもの）も書いてある。
- **文字盤のバンドル ID を `com.ohagikinakokobo.osanpo.watchkitapp.widget` に変更**（2026-11-17）：`…watchkitapp.complication` は Apple Developer で「使用できない（not available）」と出て登録できなかった（一覧にも存在しない）。
- **初めての TestFlight**（2026-11-17）：ユーザーが App Group・iCloud Container・バンドル ID 3つ・App Store Connect のアプリ・Secrets 4つを登録。クラウドで署名して **1.0.0（ビルド 10）** を App Store Connect に上げた（run 44036587029、Upload succeeded）。ビルド番号は Actions の実行番号。

## 2026-11-17 初めての試用の感想から（ユーザー決定）

- **犬の選び方**：「どの犬が選ばれているか分かりにくい」「意図しない犬に回数がつく」。原因は、犬をタップすると“追加”になる（切り替わらない）こと、犬を足すと自動で選ばれること、Watch と iPhone の選択が別々だったこと。
  - タップ＝**その犬だけに切り替え**。ながおし＝追加・はずす。2匹以上なら「みんな」。選ばれた犬はオレンジの枠とチェック。
  - ボタンのすぐ上に「**おはぎ に きろく**」と顔つきで出す。Watch はいちばん上にオレンジの帯で「おはぎ ›」（タップで選び直し）。
  - 犬を足しても選択は変えない（何も選んでいないときだけ新しい犬）。
  - **Watch は iPhone の選択に合わせる**（iPhone で選び直したときだけ。Watch で選んだものはそれまで残る）。スナップショットに `selected` を追加（古い形式も読める）。
  - 計算は WalkCore の `DogSelection`（テストあり、計21件）。
- **ボタンの表現**：「手首でうんち・おしっこがそのまま見えるのはアウト」「絵もリアル」。
  - Watch のボタンは**絵だけ（文字なし）**、iPhone は絵の下に小さく文字。文字盤・一覧・Watch の印は 💩💦 をやめ、🟤🟡（文字盤は ●・しずく）に。
  - ボタンの絵は **おはぎが主役の場面**に描き直す（おしっこ＝電柱をくんくん、うんち＝すっきり顔でおすわり、横にスコップとマナー袋（犬は袋にさわらない）、おみず＝水を飲む、ごはん＝お皿の前でおすわり）。うんち・しずくそのものは描かない。`docs/art/buttons.md` を改訂、Gemini で作成待ち。
  - 4枚とも採用（2026-11-17）：うんちの絵の描き方にそろえた。以前のしずく SVG などは削除。
