# おはぎのおさんぽ帳

おはぎきなこ工房の公式アプリ。犬の散歩中に、おしっこ・うんち・おみず・ごはんを Apple Watch や iPhone からワンタップで記録します。

- Watch で押すだけ。振動で「記録できた」がわかり、すぐ取り消せる
- ログインなし。記録は端末とご自身の iCloud の中だけ（位置情報・広告・解析なし）
- いっしょに散歩する犬をまとめて記録
- 健康の判断はしません。気になるときは動物病院へ

iPhone（iOS 17 以上）＋ Apple Watch（watchOS 10 以上）。Swift / SwiftUI。Mac を使わず、GitHub Actions のクラウドの Mac で組み立てています（`docs/ios-testflight.md`）。
